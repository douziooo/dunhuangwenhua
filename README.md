# 敦煌文化展示网站

一个基于 Vue.js 和 Element UI 的敦煌文化展示网站，展现敦煌历史、壁画、莫高窟和飞天四大主题。

## 技术栈

- **Vue.js 3** - 前端框架
- **Vue Router** - 单页面应用路由
- **Element Plus** - UI 组件库
- **Vite** - 构建工具

## 项目特色

### 设计理念
- **敦煌色彩体系**：采用壁色褐、沙色金、石青蓝、石绿绿、朱砂红、金箔黄等传统色彩
- **高级感设计**：优雅的动画效果、精致的布局、大胆的留白
- **文化融合**：传统元素与现代设计的完美结合

### 页面结构
1. **首页 - 敦煌之门**：全屏视觉冲击，动态渐变背景，导航卡片
2. **敦煌历史 - 时光长廊**：垂直时间轴展示历史发展
3. **敦煌壁画 - 壁上丹青**：网格画廊布局，支持分类筛选和详情查看
4. **敦煌莫高窟 - 崖壁佛国**：数据展示和数字洞窟体验
5. **敦煌飞天 - 天衣飞扬**：动态卡片和飞天演变时间轴

## 快速开始

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```

项目将在 `http://localhost:3000` 启动，浏览器会自动打开。

### 3. 构建生产版本
```bash
npm run build
```

构建产物将输出到 `dist` 目录。

### 4. 预览生产版本
```bash
npm run preview
```

## 注意事项

- 图片资源使用了 Unsplash 的占位图，实际项目中应替换为真实的敦煌文化图片
- 360° 全景功能需要集成专业的全景库（如 krpano 或 Pannellum）
- 建议使用高质量的图片资源以保证视觉效果

## 开发说明

项目使用 Vue 3 Composition API 编写，所有组件都采用 `<script setup>` 语法。

样式使用 CSS 变量实现主题色彩的统一管理，便于后续调整和维护。
