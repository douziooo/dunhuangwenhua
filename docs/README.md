# 敦煌文化展示网站 - 系统架构文档

## 📖 项目概述

**敦煌文化展示网站**是一个基于Vue3构建的单页应用(SPA),旨在通过现代化的Web技术展示敦煌文化的丰富内涵,包括历史沿革、壁画艺术、飞天形象和莫高窟建筑等核心内容。

| 项目信息 | 详情 |
|---------|------|
| 项目名称 | dunhuang-culture |
| 版本 | 1.0.0 |
| 描述 | 敦煌文化展示网站 |
| 开发团队 | "葱"明伶俐小组 |
| 框架 | Vue 3.3.4 + Vite 5.0 |
| UI组件库 | Element Plus 2.4.4 |

---

## 🏗️ 系统架构

### 整体架构模式

```
┌─────────────────────────────────────────────────────────┐
│                     用户浏览器                           │
└──────────────────────┬──────────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────────┐
│                    前端应用层 (SPA)                      │
│  ┌───────────────────────────────────────────────────┐  │
│  │              Vue 3 应用实例                        │  │
│  │  ┌─────────┐  ┌──────────┐  ┌─────────────────┐  │  │
│  │  │  Router │  │ Element+ │  │   自定义组件     │  │  │
│  │  │  路由   │  │   Plus   │  │   (NavBar等)     │  │  │
│  │  └─────────┘  └──────────┘  └─────────────────┘  │  │
│  └───────────────────────────────────────────────────┘  │
└──────────────────────┬──────────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────────┐
│                    表现层 (Views)                        │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐         │
│  │ Home │ │Login │ │History│ │Mural │ │Feitian│        │
│  └──────┘ └──────┘ └──────┘ └──────┘ └──────┘         │
│  ┌──────┐ ┌──────┐                                      │
│  │Mogao │ │Register│                                    │
│  └──────┘ └──────┘                                      │
└─────────────────────────────────────────────────────────┘
```

### 技术架构分层

| 层级 | 技术 | 职责 |
|------|------|------|
| **视图层** | Vue 3 SFC (Composition API) | 页面渲染、组件交互 |
| **路由层** | Vue Router 4 | 页面导航、路由守卫 |
| **组件层** | Element Plus + 自定义组件 | UI交互、表单验证 |
| **样式层** | CSS3 + CSS变量 | 主题管理、响应式布局 |
| **构建层** | Vite 5 | 开发服务器、打包优化 |

### 2. 路由系统

#### [router/index.js](file:///e:/软件工程第四届网页设计比赛/敦煌文化/src/router/index.js) - 路由配置

**功能**: 定义应用的所有路由规则和导航守卫

**路由表**:

| 路径 | 组件 | 权限 | 说明 |
|------|------|------|------|
| `/login` | Login | 公开 | 登录页面 |
| `/register` | Register | 公开 | 注册页面 |
| `/` | Home | 需登录 | 首页 |
| `/history` | History | 需登录 | 历史页面 |
| `/mural` | Mural | 需登录 | 壁画页面 |
| `/mogao` | Mogao | 需登录 | 莫高窟页面 |
| `/feitian` | Feitian | 需登录 | 飞天页面 |

**路由守卫逻辑**:
```javascript
// beforeEach守卫:
// - 检查localStorage中的isLoggedIn状态
// - 需要登录但未登录 -> 跳转/login
// - 已登录访问/login -> 跳转/
// - 其他情况 -> 正常导航
```

**scrollBehavior**: 自定义滚动行为,支持锚点定位和保存位置

### 服务器配置

需要配置URL重写规则,将所有请求重定向到index.html:

**Nginx配置示例**:
```nginx
location / {
  try_files $uri $uri/ /index.html;
}
```

**Apache配置示例**:
```apache
RewriteEngine On
RewriteBase /
RewriteRule ^index\.html$ - [L]
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule . /index.html [L]
```

## 📝 开发注意事项

### 已知限制

1. **登录验证** - 前端硬编码验证,无后端支持
2. **注册功能** - 仅模拟,无实际数据持久化
3. **用户数据** - 存储在localStorage,刷新后保留但清除浏览器数据会丢失
4. **验证码** - 前端模拟,无实际发送功能
